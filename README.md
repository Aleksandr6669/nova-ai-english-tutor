# Nova AI English Tutor (Flask + Groq Cloud)

Полнофункциональное веб-приложение на **Python (Flask)** для интерактивного изучения английского языка с виртуальным AI-персонажем **Nova**, работающим на базе моделей **Groq**.

---

## 🚀 Архитектура и возможности

1. **Система аутентификации**:
   - Регистрация пользователя по связке: логин (username), электронная почта (email) и пароль.
   - Вход в аккаунт по почте и паролю.
   - Безопасное хранение хэшей паролей с солью (`Werkzeug.security` / PBKDF2:SHA256).
   - База данных: локальная встроенная SQLite (`tutor.db`), создается автоматически.

2. **Интеграция с Groq Cloud (API)**:
   - Поддерживаемые передовые модели:
     - `llama-3.3-70b-versatile` (флагманская модель для глубокого объяснения нюансов языка и свободной беседы);
     - `llama-3.1-8b-instant` (сверхбыстрый отклик);
     - `mixtral-8x7b-32768` (длинный контекст и высокая скорость);
     - `gemma2-9b-it` (легковесная точная модель).
   - Ввод и безопасное сохранение персонального API-ключа Groq в настройках аккаунта.

3. **Интерактивный виртуальный персонаж**:
   - Анимированная светящаяся сфера-аватар с кольцами и частицами.
   - Динамическая реакция на 4 состояния:
     - *Ready / Idle* (мягкая плавная пульсация);
     - *Listening* (активный микрофон, индикатор захвата речи);
     - *Thinking* (вращение и обработка запроса в Groq);
     - *Speaking* (анимация звуковых волн и вибро-пульс при озвучке).
   - Контейнер `#avatar-viewport` полностью подготовлен для интеграции Three.js / 3D-модели (GLTF/GLB).

4. **Голосовые функции**:
   - **Голосовой ввод (Speech-to-Text)** через Web Speech API (`webkitSpeechRecognition`) на английском языке.
   - **Голосовой вывод (Text-to-Speech)** через `speechSynthesis` с настройкой скорости речи, тона и переключателем авто-озвучивания ответов.

5. **Педагогическая логика ассистента**:
   - Адаптация под уровни CEFR: Beginner (A1–A2), Intermediate (B1–B2), Advanced (C1–C2).
   - Стили: разговорный (Casual), грамматический фокус, деловой английский, подготовка к IELTS/TOEFL.
   - Автоматический разбор и подсветка ошибок пользователя карточкой `[Correction]`.

## 📦 Быстрый запуск Flask-приложения

### Шаг 1. Распаковка архива или клонирование
```bash
git clone https://github.com/Aleksandr6669/nova-ai-english-tutor.git
cd nova-ai-english-tutor
```

### Шаг 2. Создание виртуального окружения (рекомендуется)
```bash
# macOS / Linux
python3 -m venv venv
source venv/bin/activate

# Windows
python -m venv venv
venv\Scripts\activate
```

### Шаг 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 4. Запуск приложения
```bash
python app.py
```
После запуска в терминале появится сообщение:
```
Starting English AI Tutor Flask Server on http://127.0.0.1:5000 ...
```
Откройте в браузере: **`http://127.0.0.1:5000`**

---

## 🔑 Подключение Groq API
1. Зарегистрируйтесь на бесплатном портале Groq: [console.groq.com/keys](https://console.groq.com/keys)
2. Создайте API-ключ (начинается с `gsk_...`).
3. В приложении нажмите кнопку **«Настройки»** в правом верхнем углу, вставьте ключ и сохраните.
4. Выберите желаемую модель (по умолчанию `llama-3.3-70b-versatile`).
