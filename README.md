# Nova AI English Tutor (SPA + Flask + Groq Cloud)

Полнофункциональное веб-приложение (Single-Page Application / Flask) для интерактивного изучения английского языка с виртуальным AI-персонажем **Nova**, работающим на базе моделей **Groq Cloud**.

---

## 🚀 Архитектура и возможности

1. **Архитектура Single-Page Application (SPA)**:
   - Полная отрисовка и динамическое управление состоянием без перезагрузок страницы.
   - Мгновенный отклик: диалог, выбор тем, переключение языков, открытие шторки настроек происходят на лету без перехода по страницам.
   - Локальное сохранение истории диалогов и настроек (`localStorage`), нулевая задержка при повторном открытии.

2. **Интеграция с Groq Cloud (API)**:
   - Актуальные флагманские модели Groq:
     - `openai/gpt-oss-120b` (Флагманская модель 120B параметров со скоростью до 500 токенов/сек: детальные объяснения правил, грамматики и живой диалог);
     - `openai/gpt-oss-20b` (Сверхбыстрая модель 20B параметров со скоростью до 1000 токенов/сек);
     - `qwen/qwen3.8-27b` (Сбалансированная модель для диалогов и симуляций интервью).
   - Встроенный механизм **Auto-Fallback**: при обращении к устаревшим моделям или возникновении 404 ошибки сервис автоматически переключается на `openai/gpt-oss-120b` без прерывания диалога.

3. **Раздельные голосовые режимы**:
   - 🎙️ **Режим диктовки (Кнопка микрофона)**:
     - Однократная запись реплики пользователя.
     - Голос в реальном времени транскрибируется в поле ввода и отправляется.
     - После ответа ассистента микрофон остаётся выключенным.
   - 🟣 **Режим «Лайв-общение» (Фиолетовая кнопка со звуковыми волнами)**:
     - Непрерывный разговор в формате «hands-free».
     - Пользователь говорит -> Nova генерирует ответ и озвучивает его голосом (TTS) -> по окончании озвучки микрофон автоматически активируется через 350 мс для следующей реплики.
     - Пользователь может свободно общаться без нажатия кнопок.

4. **Интерактивный виртуальный аватар Nova**:
   - Анимированная сфера-аватар с кольцами и частицами.
   - 4 динамических состояния:
     - *Ready / Idle* (мягкая плавная пульсация);
     - *Listening* (активный микрофон, индикатор захвата речи);
     - *Thinking* (вращение и обработка запроса в Groq);
     - *Speaking* (анимация звуковых волн и вибро-пульс при озвучке).

5. **Педагогическая логика ассистента**:
   - Полное двуязычие: Nova одинаково свободно понимает русский и английский языки.
   - Адаптация под уровни CEFR: Beginner (A1–A2), Intermediate (B1–B2), Advanced (C1–C2).
   - Автоматический разбор и подсветка ошибок пользователя карточкой `[Correction]`.

## 📦 Быстрый запуск Flask-приложения

```bash
unzip english_tutor_flask_app.zip -d english_tutor
cd english_tutor
pip install -r requirements.txt
python app.py
```
Откройте в браузере: **`http://127.0.0.1:5000`**

---

## 🔑 Подключение Groq API
1. Зарегистрируйтесь на бесплатном портале Groq: [console.groq.com/keys](https://console.groq.com/keys)
2. Создайте API-ключ (начинается с `gsk_...`).
3. В приложении нажмите кнопку **«Настройки»** в правом верхнем углу, вставьте ключ и сохраните.
